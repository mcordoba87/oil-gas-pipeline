CÓMO CARGAR CADA MOCK (RUNBOOK)
===============================================================================
Todos los comandos se corren desde la raíz del proyecto con el .venv.
El stack ya está arriba: docker compose ps (todo healthy).

1) MASTER OLTP (si está vacío)
   .venv/bin/python generators/seed_oltp.py            # siembra inicial 25 pozos
   .venv/bin/python generators/seed_oltp.py --refresh  # simula operación

2) STREAMING (simulador + worker, proceso continuo)
   bash scripts/start_streaming.sh                     # ambos en background
   # o corrida acotada:
   .venv/bin/python generators/sensor_simulator.py --pozos 25 --duracion 120

3) BATCH DIARIO (producción, laboratorio, precios, SCADA, extract OLTP)
   .venv/bin/python generators/daily_production_csv.py
   .venv/bin/python generators/daily_lab_csv.py
   .venv/bin/python ingestion/extract_oltp.py
   .venv/bin/python generators/fetch_prices.py
   .venv/bin/python generators/scada_logs.py
   # para historial, pasar --fecha YYYY-MM-DD en los CSV

4) MAESTROS TSDB + LOADER MinIO -> TSDB
   .venv/bin/python generators/seed_tsdb.py
   .venv/bin/python ingestion/load_landing_to_raw.py

5) DBT Y VERIFICACIÓN
   bash scripts/verify_dbt.sh    # dbt run + test + snapshot + conteos marts
   bash scripts/verify_tsdb.sh   # esquema, agregados, políticas

6) CRON (automatiza batch; AÚN NO instalado - roadmap item 19)
   bash cron/setup_cron.sh
